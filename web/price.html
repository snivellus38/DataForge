One

So where did the rule go?

The weights are identical — same hash, byte for byte. Yet removing one line changed the answer. Whatever held that rule was written somewhere else, and thrown away when the line disappeared.

That is the whole fork in test-time adaptation. The other route optimises: HRM (arXiv:2506.21734) and TRM (arXiv:2510.04871) turn an unseen task's demonstrations into training samples and take a backward pass before answering. Here the parameter count that changed is zero, and the adaptation lives in state that did not exist a second ago.

It was written into σ: a matrix built fresh on every forward pass. Each token adds one rank-one update, and the model answers by reading it back.

σt = σt−1 + rope(K)t ⊗ Vt outt = σt⊤ rope(Q)t

Is any of this actually running?

A convincing animation would look identical. So here is a check an animation cannot fake. The reference implementation computes attention the parallel way — a full token×token score matrix. We compute the same layer the recurrent way, accumulating σ token by token.

If σ were decoration, the two would disagree.

Three

What that buys, one:
neurons that mean something

Because activations are non-negative and sparse, a neuron either participates or it does not — there is no cancelling. That makes "what does this neuron respond to?" a question with an answer.

Pick a concept. These are the neurons of the 8M model that prefer it more than chance allows.

The control matters more than the result. A neuron that fires on five bytes in the whole corpus is trivially 100% selective. So every neuron here is tested against its own permutation null — concept labels shuffled, its activations held fixed, 2,000 times. Only neurons beating their own 95th percentile count, and the headline survives Benjamini–Hochberg at 5% FDR.

Four

What that buys, two:
synapses you can watch

BDH's claim is not really about neurons, it is about synapses. There is a standing neuron-to-neuron graph G* = Dx⊤E⊤, computed from the weights with no data at all.

Below, specific wired pairs light up as the sentence runs — the Hebbian product xi(t)·xj(t) on a wire that already existed. Press play.

Careful: this is not σ. σ is N×D, not neuron×neuron, so it cannot be read as a weight between two named neurons. G* can. Different objects.

Five

What that buys, three:
the wiring predicts the silence

G* is computed from two weight matrices and nothing else. It has never seen French.

Yet it tells you, in advance, which neurons will do nothing at all. Neurons with no synapse above threshold are almost exactly the neurons that never fire on the whole corpus.

Structure predicts function. The dark half of THE FIELD is not a rendering artifact — it is the disconnected half of the graph.

Six

And here is the bill

A fixed-size state must fill up. The obvious guess is that it holds about as many rules as it has rows. The obvious guess is wrong, and being wrong about it is the most useful thing on this page.

Below, k bindings are written into a state and read straight back. No model, no training — just the geometry.

Two ReLU'd Gaussians overlap by 1/π on average. Every pair. Unavoidably. Let the keys go negative and they become orthogonal on average, and the same state holds bindings past its own rank.

Non-negativity is what made the last three slides possible. It is also what makes this one fail.

This ceiling is not news to the field, and that is the point: DeltaNet (arXiv:2406.06484) exists because “the additive update in linear transformers” — precisely the write BDH uses — is weak at associative recall, and replacing it with the delta rule is reported to fix that. What is ours is the mechanism and the constant: the overlap is 1/π, it comes from the ReLU, and a signed-key counterfactual removes it.

Seven

Two curves that look the same
and mean different things

Here is a mistake worth showing, because we made it. Train the toy on k ∈ [2, 10] and it degrades past k=12. It looks exactly like a state filling up.

It is not. Measure the same state directly and it still retrieves 95% at k=32 — far past where the model fails.

The model curve is an extrapolation limit, set by the range of k it was trained on. The state curve is associative capacity, set by key overlap. Calling the first one "interference" is a factual error.

This is why the capacity result on the previous slide is measured on σ directly and not inferred from a training run.

Eight

A replication that failed,
and what it taught us

The Dragon Hatchling paper says two BDH models can be concatenated into one larger model — §7.1, "Model merging: concatenating two models". Join every tensor with an n dimension, average the rest.

We have two 8M models, French and Portuguese. We ran the recipe exactly. It produced iiiiiiii.

So we ruled things out. RoPE handling? No — concatenating the frequency buffers as the paper says still collapses. The residual doubling? No — halving E halves the logits exactly and the output is still degenerate.

What is left is the paper's own precondition: its two models are clones of a common base. Ours were trained independently. Concatenation along n is well defined structurally — but a neuron's meaning is only shared between models descended from one initialisation.

Not a refutation. The paper's Table 2 is for forked models. We have no common base to fork from, so we tested a harder case it never claims.

Nine

Where this lives in BDH-CQ

Everything so far ran on models we trained. BDH-CQ writes demonstrations into a contextual memory S with frozen parameters. The report gives the update in its general form — and then names the special case linear attention realises:

St = Uθ(St−1, Dt)general form St = St−1 + Uθ(Dt)the special case arXiv:2608.09888 §3.2, p.3 — "linear attention being the conceptually simplest standalone realization… capturing the special case"
One correction, and it is on the problem statement itself. It is tempting to say BDH-CQ's memory is additive accumulation. The report does not say that. Equation (1) is the general Uθ; additive accumulation is named as a special case, and the actual rule is proprietary. We can show you the special case because it is what the public code computes. We cannot show you theirs.

Answering happens in a second state. A workspace H is refined R times against the finished memory, and only the last step is decoded — reasoning with no verbal trace:

H0 = Eθ(x★, SK) Hr+1 = Fθ(Hr, SK)same θ, applied R times ŷ = Gθ(HR) arXiv:2608.09888 §3.3, eqs. (2)–(4), p.3. The report never states a value for R, and never says what changes between its effort levels.

Our model has that shape in miniature, for a reason that surprised us: the reference bdh.py is weight-tied across layers. Its encoder and decoders are built once and reused, so n_layer is not depth — it is how many times one operator runs. You can watch all six →

    Say it back

    Demonstrations are weights you write at inference time: a frozen model adapts by adding rank-one updates to a fixed-size associative state, so changing only the demonstrations changes the answer — but that state's capacity is set by how much its keys overlap, not by its size, so the non-negativity that makes BDH inspectable is also what makes it forget sooner.
